# Google LocalMatch

Google LocalMatch is a smart local business comparison web application.

The goal is simple:

> Find the right place, not just a place.

## Features

- Search local businesses
- Google Places API integration
- Location-based search
- Budget filtering
- Distance filtering
- Open-now filtering
- Smart Match Score
- Business comparison
- Recommendation reasons
- Google Maps directions
- Responsive design

## Technology

- Next.js
- React
- TypeScript
- Google Places API
- CSS
- Google Maps
